# 잡카드 한번에 판매

값이 낮은 카드의 중복분을 한 번에 파는 기능을 만든다. 이 문서는 「잡카드」를 무엇으로 가를지
데이터로 정하고, 무엇을 팔고 무엇을 남길지, 화면을 어디에 붙일지 정리한다.

## 1. 문제는 금액이 아니라 횟수다

sv10 100팩을 연 상태를 시뮬레이션했다(앱과 같은 칸·가중치 모델).

| | 카드 | 종류 | 중복 |
|---|---:|---:|---:|
| sv10 100팩 | 1,000장 | 193종 | **807장 (164종)** |
| sv10 300팩 | 3,000장 | 208종 | 2,792장 (185종) |
| base1 30팩 | 300장 | 89종 | 211장 (64종) |

지금 이 807장을 팔려면 카드 상세로 들어가 한 종씩 파는 수밖에 없다. **164번 들어가고 164번
확인을 누른다.** 카드를 여는 것은 재미인데 정리는 노동이고, 그래서 아무도 정리하지 않는다.

돌아오는 값은 sv10 100팩 기준 약 31만원이다. 팩 값이 300만원 남짓이니 10% 정도가 정리로
회수된다 — 무시할 액수는 아니지만, 이 기능을 만드는 이유는 그쪽이 아니다.

## 2. 등급으로는 잡카드를 가릴 수 없다

등급을 기준으로 삼고 싶어지지만 값과 어긋난다.

| 등급 | 중앙값 | 최소 | 최대 |
|---|---:|---:|---:|
| C | 427원 | 83원 | **53,481원** |
| U | 482원 | 138원 | 45,455원 |
| RR | 3,180원 | **69원** | 1,493,652원 |

**커먼 한 장이 53,481원이고, 게임에서 가장 싼 카드(69원)는 RR 이다.** 「커먼은 전부」로 팔면
5만원짜리를 버리고, 「RR 이상은 남긴다」로 두면 69원짜리가 남는다. v0.4.0 에서 컬렉션 정렬과
도감 난이도를 값 기준으로 바꾼 것과 같은 이유로, 여기서도 기준은 값이다.

### 임계값이 실제로 하는 일

전체 1,284장의 분포다.

| 임계값 | 해당 카드 | 비중 |
|---|---:|---:|
| 1,000원 | 651장 | 51% |
| 3,000원 | 861장 | 67% |
| 5,000원 | 959장 | 75% |
| 10,000원 | 1,065장 | 83% |

중요한 것은 개수와 값이 갈리는 정도다. sv10 300팩에서 중복 2,792장 중 1,000원 이하가
2,725장(**개수의 98%**)인데, 그 값은 109만원으로 전체 중복 270만원의 **40%** 다. 나머지 2%
가 값의 60%를 들고 있다. 임계값은 그 2%를 지키는 장치다.

세트에 따라 적정선이 크게 다르다. base1 30팩에서는 1,000원 이하 중복이 48장(4만원)뿐이고,
10,000원까지 올려야 197장(47만원)이 잡힌다. 옛날 세트는 커먼도 비싸다. 그래서 임계값은
고정하지 않고 고르게 하고, 지금 걸린 세트 필터를 그대로 따른다.

## 3. 규칙

**중복만 판다. 마지막 한 장은 남긴다.** 단일 판매가 이미 그 규칙이고, 여기서 깨면 잃는 것이
크다 — 마지막 장을 팔면 도감 진행이 되돌아가고, 컬렉션에서 그 카드가 사라지며, 되돌릴 방법이
없다. 한 장을 남겨도 정리 효과는 그대로다: 잡카드는 계속 중복으로 쌓이므로 이 기능은 반복해서
쓰는 청소 도구가 된다.

**임계값은 카드 한 장의 값을 본다.** 「3장 합쳐 3,000원」이 아니라 「한 장이 1,000원 이하」다.
합계로 두면 많이 가진 카드가 비싼 카드로 취급된다.

**지금 걸린 세트·등급 필터를 그대로 따른다.** 목록에 안 보이는 카드가 팔리면 안 된다.

**판매 추가금(`dustBonus`)을 적용한다.** 단일 판매와 같은 값이어야 한다.

## 4. 화면

컬렉션 탭의 「보기 방식」 줄에 **「한번에 판매」** 버튼을 붙이고, 누르면 **화면을 통째로 내준다**
(카드 상세·도감 상세와 같은 방식이다. 팝오버라 모달을 쓸 수 없어 탭 안에서 화면만 바꾼다).

```
← 한번에 판매
얼마 이하인 카드의 중복분을 팔까요?
[1,000원] [3,000원] [5,000원] [7,000원] [10,000원]
36종 · 72장 · +9,414,000원
────────────────────────────
(격자 — 팔릴 카드. 배지는 사라질 장수)
────────────────────────────
             [한번에 판매]
```

**임계값을 누르면 아래 격자가 그 임계값의 대상으로 바뀐다.** 되돌릴 수 없는 동작이라 무엇이
사라지는지 눈으로 보고 누르게 한다. 배지는 가진 장수가 아니라 **팔릴 장수**(`−2`)를 적는다.

확인은 인라인이다. `.alert` 과 `.sheet` 은 팝오버가 닫힐 때 고아 창을 남기므로 이 앱에서 금지다.
확인 문구에 「한 종류에 한 장씩은 남습니다. 되돌릴 수 없어요.」를 적는다.

임계값 후보는 **1,000 / 3,000 / 5,000 / 7,000 / 10,000원** 다섯 개이고 마지막 선택을 기억한다
(`@AppStorage`, 컬렉션의 「보유한 카드만」과 같은 방식). 중복이 하나도 없으면 들어가는 버튼
자체를 띄우지 않는다.

## 5. 코드

`WalletStore` 에 셋을 더한다. 대상을 고르는 것과 값을 세는 것과 실제로 파는 것을 나눈다 —
「무엇이 팔리는가」는 순수 함수라야 검증할 수 있다.

```swift
struct BulkSale: Equatable, Sendable {
    var kinds = 0        // 종류 수
    var copies = 0       // 장수
    var tokens = 0       // 받는 값
}

/// 값이 임계값 이하인 카드의 중복분을 고른다. 순수 함수다.
static func bulkSaleTargets(_ entries: [CardEntry], maxWon: Int,
                            spares: (String) -> Int,
                            prices: CardPrices?) -> [String]

/// 팔면 무엇이 얼마인가. 상태를 바꾸지 않는다 — 화면이 매 프레임 부른다.
func bulkSalePreview(_ targets: [String]) -> BulkSale

/// 고른 카드의 중복분을 전부 판다. **저장은 한 번만 한다.**
@discardableResult
func sellSpares(_ targets: [String]) -> BulkSale
```

후보 목록은 화면이 넘긴다. 세트·등급 필터와 카드 목록은 화면에 있고 `WalletStore` 는 카드를
모른다 — 그래서 「목록에 안 보이는 카드는 팔리지 않는다」가 구조로 보장된다.

`sellSpares(cardID:tier:count:)` 를 164번 부르면 `save()` 가 164번 돌고 도감 혜택도 164번
다시 계산된다. 한 번에 지우고 한 번만 저장한다.

### 테스트로 잠근 것

`BulkSaleTests` 7개다.

- 마지막 한 장은 절대 팔리지 않는다 (한 장뿐이면 대상에도 안 든다)
- 임계값을 넘는 카드는 한 장도 팔리지 않는다
- 미리보기 결과와 실제 판매 결과가 같다
- 받은 값 = 팔린 장수 각각의 `CardSale.price` 합계 (판매 추가금 포함)
- 잔액이 그만큼 오르고 **종수는 줄지 않는다** (줄면 마지막 장이 팔린 것이고 도감이 되돌아간다)
- 120종 정리가 1초 안에 끝난다 (종류마다 저장하면 넘긴다)
- 시세를 모르는 카드는 잡카드로 잡힌다
- 임계값 후보 다섯 개가 서로 다른 범위를 잡는다

## 6. 하지 않을 것

**마지막 장 판매.** 위 3절의 이유다. 원한다면 카드 상세에서 한 장씩 파는 길을 따로 열어야
하고, 그건 이 기능이 아니다.

**등급 기준 정리.** 2절에서 값과 어긋남을 확인했다.

**개봉 직후 자동 판매.** 임계값을 정해 두면 팩을 열 때 알아서 팔아 주는 방식이 편해 보이지만
넣지 않는다. 「중복 회피」를 뺀 것과 같은 이유다 — 내가 뽑은 카드에 무언가 몰래 개입해 결과를
바꾸면, 도와주려던 장치가 뽑기를 망친 것으로 남는다. 정리는 내가 눌러서 일어나야 한다.

## 7. 정해진 것

| | |
|---|---|
| 들어가는 방식 | 버튼을 누르면 **새 화면** |
| 임계값 후보 | 1,000 / 3,000 / 5,000 / 7,000 / 10,000원 |
| 임계값을 누를 때 | 대상 카드를 격자로 보여 준다 |
| 이름 | **한번에 판매** |
| 마지막 한 장 | 남긴다 |

## 8. 남은 것

요청서의 **2번 항목이 비어 있다.** 함께 넣을 것이 있었다면 알려 주면 이 문서에 더한다.

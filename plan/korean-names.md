# 한국어 카드 이름 — 확인과 수정

17,666장 전부에 한국어 이름이 들어갔다. 다만 **채워졌다는 것과 맞다는 것은 다른 문제**였다.
이 문서는 확인 결과와 고친 것을 적는다.

## 1. 어디서 오는가

| 출처 | 장수 | 무엇인가 |
|---|---:|---|
| 한국판 대조 | 14,435 | 한국에 실제로 찍힌 카드와 짝지은 것 |
| 번역 | 1,573 | 한국 발매판이 없어 옮겨 적은 것 |
| 손으로 확정 | 738 | `ko-overrides.json` 에 사람이 적은 것 |
| 규칙 조립 | 619 | 공식 종족명 + 소유자 + 꼬리표 |
| 같은 이름에서 옮김 | 301 | 같은 영문 이름의 다른 판본 |

출처는 `data/ko-name-sources.json` 에 카드별로 남는다. 「번역」이 정식 명칭이 아닌 자리이고,
나중에 한국 발매판이 생기면 그 자리만 갈아 끼우면 된다.

## 2. 확인해서 나온 것 — 번역기가 웹 문구를 넣고 있었다

번역 fallback 을 번역 메모리 API(MyMemory)로 채웠는데, **짧은 카드 이름에는 번역이 아니라
남의 웹페이지 문구가 붙어 들어왔다.**

| 카드 | 들어가 있던 한국어 |
|---|---|
| Blaine | 뚱 베어 |
| Archie | 인기 카테고리 |
| Absol G LV.X | 소프트웨어 |
| Accompanying Flute | 공급 업체 |
| Drasna | 사이트맵 |
| Bronzong G | 윤리경영 |

같은 한국어가 서로 다른 카드 여럿에 붙은 것이 29 무리였다. 그럴듯한 한국어라 눈으로는
걸러지지 않는다 — 「소프트웨어」가 카드 이름으로 떠 있어도 이상하다고 느끼기 전에 넘어간다.

**고친 방법.** 트레이너·에너지 617개를 손으로 다시 적었다. 적을 때는 `ko-pool.json`(한국에
실제로 찍힌 카드 이름 3,227개)에 있는지 대조했고, 있는 것은 그 표기를 그대로 썼다.

## 3. 두 번째 문제 — 자동 대조가 엉뚱한 카드를 집었다

일러스트레이터와 그림으로 한국 카드와 짝짓는데, **같은 작가가 그린 다른 카드**를 집는 일이
있었다.

- Hau · Lana · Mallow 가 모두 「마오」
- Crystal Cave 와 Stormy Mountains 가 서로의 이름을 바꿔 달았다
- Electric Memory · Fire Memory · Water Memory 가 모두 「워터메모리」

**고친 방법.** 한 한국어 이름을 서로 다른 영문 카드가 나눠 가지면 그 대조를 통째로 버린다.
어느 쪽이 맞는지 알 수 없기 때문이다. 62개 이름(카드 205장)이 버려졌고, 그 자리는 규칙
조립과 손으로 적은 이름이 이어받았다.

손으로 확정한 이름이 자동 대조를 이기도록 순서도 바꿨다. 원래 의도가 그것이었는데
코드가 반대로 되어 있었다.

## 4. 규칙 조립을 넓혔다

번역기에 맡기던 포켓몬 이름을 규칙으로 옮겼다. 공식 종족명(PokéAPI)이 있으면 번역할 이유가
없다.

- **팀 마크** — `Absol G`, `Luxray GL`, `Bronzong E4`, `Blaziken FB`, `Rayquaza C`
- **LV.X · δ · LEGEND** — 이름 끝에 여러 개가 붙어도 순서를 지켜 다시 잇는다
- **지역 폼** — 알로라 · 가라르 · 히스이 · 팔데아
- **메가** — `M Charizard-EX` → `M리자몽 EX`
- **두 종족** — `Entei & Raikou LEGEND` → `앤테이&라이코 LEGEND`
- **성별 기호** — `Nidoran ♀` → `니드런♀`

띄어쓰기가 시대마다 갈리는 것(썬&문은 「알로라나인테일 GX」, 검&방패 이후는 「알로라 나시 ex」)은
두 표기를 다 만들어 보고 **한국 카드 이름 표에 실제로 있는 쪽**을 고른다.

## 5. 테스트로 잠근 것

- 카드 이름에 웹 문구가 없다 (「카테고리」·「사이트맵」·「소프트웨어」 등 22개 낱말)
- 서로 다른 카드가 같은 한국어 이름을 쓰지 않는다
- 이름에 영문이 남아 있지 않다 (등급 꼬리표와 팀 마크는 예외)
- 한 장도 빠짐없이 한국어 이름이 있다

## 6. 남은 것

**「번역」1,573장은 정식 명칭이 아니다.** 한국 발매판이 없는 카드라 옮겨 적은 것이고,
읽을 수 있는 한국어이지만 공식 표기와 다를 수 있다. 어느 카드인지 `ko-name-sources.json`
에 남겨 두었으므로 나중에 발매판이 생기면 그 자리만 바꾸면 된다.

**버린 대조 62개**는 둘 중 하나는 맞았을 것이다. 어느 쪽인지 가리려면 카드 번호까지 맞춰
봐야 하는데, 판마다 번호가 다시 매겨져 지금 가진 데이터로는 못 한다.
